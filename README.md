# 三十秒报价 ERP｜电脑装机与强弱电工程业务管理系统

> 面向电脑销售、装机、IT 服务，以及强弱电与安防工程商的业务管理系统。围绕产品和库存、报价、合同、送货、维修、回收、收付款与项目成本，帮助团队把日常业务放进一套连贯的流程中管理。

**项目版本：v1.5.1** · **技术栈：PHP 7.4 / MySQL 5.7 / 原生 HTML、CSS 与 JavaScript** · **许可证：MIT**

## 客户等着报价，别再让一张单子耗掉一上午

早上刚接到客户的电脑配置或工程需求，你还要翻产品表找型号、逐项核价、排报价清单，再根据客户修改来回调整报价和合同。一上午过去了，客户还在等回复。

现在，从 **3 万级产品库**快速选型，套用报价与合同模板，常见业务约 **30 秒**即可完成报价和合同。少花时间核对品牌、型号和参数，把精力留给跟进客户和交付项目。

## ✨ 功能模块

以下模块与系统侧边栏的“主要功能”“基础数据”“公司设置”“系统管理”和“帮助与支持”分组对应。

### 主要功能

- **🏠 工作台** — 汇总客户、供应商、产品、报价、合同、维修及应收应付数据；展示逾期提醒、本月收支和近期业务单据
- **📋 报价管理** — 提供组装电脑、品牌整机、弱电工程和强电工程报价；支持常用配置、审核、利润核算、单据风格、打印及 Word/Excel 导出；可选择开票方式并按公司设置计算报价加收金额
- **📐 方案管理** — 管理 IT 技术方案，记录项目技术细节和实施内容，支持附件
- **📝 合同管理** — 管理销售、施工、IT 外包和租赁等合同；参照《民法典》标准格式并结合实际业务场景优化合同模板，记录条款，跟踪草稿、生效、完成及取消状态
- **🚚 送货管理** — 从已审核报价生成送货单，支持自送、快递和虚拟发货；跟踪审核、送货状态及收款，并支持打印和导出
- **🔧 维修管理** — 登记上门或带回维修工单，记录设备、故障、配件和费用，跟踪维修进度与工程师处理；支持打印 58mm/80mm 热敏小票
- **♻️ 电脑回收** — 登记二手设备回收、付款和验机结果，跟踪回收成本及转卖、拆件、报废等处置进度
- **💰 财务管理** — 管理应收、应付与收付款记录；支持由送货单生成应收、收款生成收据，并提供收据管理、利润报表和总账
- **📊 项目成本** — 按项目汇总应付账单与人工成本，跟踪项目成本并核算毛利

### 基础数据

- **🏢 客户管理** — 维护客户档案、标签和客户简称，支持导入导出
- **🚚 供应商管理** — 维护供应商档案，支持导入导出
- **📦 产品管理** — 管理 SKU、分类、采购入库、销售出库、租借、库存、序列号和价格历史；支持产品导入导出，并可进入退换货管理（RMA）

### 公司设置

- **⚙️ 公司设置** — 配置公司资料、报价与开票加收比例、报表页脚、水印和 Logo；详见[报价开票加收规则](QUOTE_INVOICE_TAX.md)
- **🔏 公章管理** — 管理电子公章，并用于报价单、送货单和合同等业务单据
- **👥 用户管理** — 管理系统用户及角色权限

### 系统管理

- **🛡️ 系统管理** — 管理系统版本与更新
- **📋 操作日志** — 查看系统操作和登录记录

### 帮助与支持

- **💬 问题反馈** — 提交功能建议或问题，并跟踪回复

## 项目特点

### 从报价到回款的业务衔接
报价、合同、送货、应收和收款记录可以衔接处理，减少重复录入，并便于追踪订单执行和回款情况。

### 产品库存与售后流程
采购入库、销售出库、租借、序列号追踪和返修等功能围绕产品资料协同，帮助记录库存变化与设备流转。

### 面向客户的单据输出
报价单、送货单、合同和收据支持公司信息与单据风格配置；报价、送货及合同可使用电子公章。

## 源码服务器部署（可选）

### 环境要求

- PHP 7.4
- MySQL 5.7
- Nginx（或已正确配置 PHP 的 Apache）
- PHP-FPM 与 Web 服务的连接方式按实际服务器配置

### 获取代码与配置

```bash
git clone https://github.com/kaier0922/myerp.git
cd myerp
cp config.example.php config.php
cp sms_config.example.php sms_config.php
```

编辑本地 `config.php`，填写数据库地址、数据库名、账号、密码、邮件配置和授权密钥。需要短信登录时，再填写 `sms_config.php` 中的腾讯云短信配置。不要将包含真实密钥的本地配置提交到 GitHub。

### 数据库初始化状态

> 当前仓库尚未提供完整的全新安装数据库结构文件，因此仅凭本仓库无法完成空数据库初始化。部署前需要获取与 v1.5.1 匹配的空库结构包。仓库中的迁移脚本不能替代初始化结构；执行迁移前应先备份数据库。

### Nginx 配置参考

按服务器上的 PHP-FPM socket 和项目实际路径调整以下配置：

```nginx
server {
    listen 80;
    server_name example.com;
    root /var/www/myerp;
    index index.php index.html;

    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        fastcgi_pass unix:/run/php/php7.4-fpm.sock;
    }

    location ~* ^/uploads/.*\.(php|php5|phtml)$ {
        deny all;
    }

    location ~ /\. {
        deny all;
    }
}
```

上传目录需要由 Web 服务账号按最小权限写入。正式环境应启用 HTTPS，并限制诊断、迁移等管理脚本的访问。
