# 30秒电脑装机强弱电工程报价管理系统

> 某个下午手搓的装机管理系统，自己用得挺好的，应该是涵盖了这个行业大部分业务需求，平时有空就修修改改，现在基本完善了，就开源出来了。

如果你也是开电脑店、电脑公司、做IT服务的同行，希望这个项目对你有帮助,完全可以做到一个货物和费用的闭环。

> 🎉 **v1.5 已发布**：新增电脑回收模块、项目成本管理模块；组装机报价支持一键填套数+单独计算标记；财务新增利润报表；报价管理新增常用配置；方案/合同管理、产品库分类加载等持续优化；维修单/送货单打印水印效果修复。

## ✨ 功能模块

与左侧导航菜单一一对应：

### 主要功能
- **🏠 工作台** — 汇总客户、供应商、产品、报价、合同、维修及应收应付数据；查看逾期提醒、本月收支和近期报价、合同
- **📋 报价管理** — 支持组装电脑、品牌整机、弱电工程、强电工程报价；可保存常用配置、走审核流程、切换单据风格、打印或导出，并进行利润核算；支持选择电子普票或增值税专票，按公司设置的比例计算报价加收金额
- **📐 方案管理** — 管理 IT 技术方案，记录项目技术细节与实施方案，支持附件
- **📝 合同管理** — 管理销售、施工、IT 外包、租赁等合同，使用合同模板记录条款与执行状态，跟踪草稿、生效、完成或取消
- **🚚 送货管理** — 从已审核报价生成送货单，支持自送、快递、虚拟发货，跟踪送货状态、审核及收款情况，并支持单据打印和导出
- **🔧 维修管理** — 登记上门或带回维修工单，记录设备信息、故障、配件与费用，跟踪维修进度和工程师处理；支持打印 58mm/80mm 热敏维修小票
- **♻️ 电脑回收** — 登记二手设备回收与付款，记录验机、分拣和回收成本，并跟踪设备转卖、拆件或报废等处置进度
- **💰 财务管理** — 管理应收、应付和收付款记录；支持由送货单生成应收、收款生成收据，并提供收据管理、利润报表与总账
- **📊 项目成本** — 按项目汇总应付账单和人工成本，跟踪项目成本并实时核算毛利

### 基础数据
- **🏢 客户管理** — 客户档案，支持标签分类、客户简称、支持导出导入
- **🚚 供应商管理** — 供应商档案管理、支持导出导入
- **📦 产品管理** — 产品库，支持SKU、分类、采购管理销售出库管理、租借管理、序列号追踪、价格历史、支持导出导入（进销存基本上都在产品管理里完成闭环），页面内可直接进入**退换货管理**（RMA工单）

### 公司设置
- **⚙️ 公司设置** — 公司信息、报表页脚、水印、Logo 等配置
- **🔏 公章管理** — 电子公章上传管理，报价单/送货单/合同均可盖章
- **👥 用户管理** — 多用户，角色权限控制

### 系统管理
- **🛡️ 系统管理** — 版本检查与更新管理
- **📋 操作日志** — 系统操作记录、登录历史

### 帮助与支持
- **💬 问题反馈** — 用户提交问题反馈/建议，支持回复跟踪

## 🎯 亮点

### 报价单多模板
针对IT行业不同业务场景设计了四套报价模板：
- 弱电工程报价
- 强电工程报价
- 品牌电脑报价
- 组装机报价（内置配件兼容性校验逻辑）

### 组装机兼容性校验
组装机报价模板内置了 CPU/主板/内存/的兼容性校验逻辑，选配件时自动提示不兼容项，用着挺顺手的。

### 单据风格切换
报价单、送货单支持多套打印风格实时切换（经典黑白、商务蓝、暖橙金、少女粉等），切换后直接打印，客户看着也不一样。给老板娘就使用少女或者萌宠，给老中就直接使用商务和中式红印

### 电子公章
上传公章图片后，可在报价单/送货单/合同上拖拽盖章，打印时位置固定不偏移。

## 🚀 部署说明

### 环境要求
- PHP 7.4+
- MySQL 5.7+
- Nginx 或 Apache

### 安装步骤

**1. 克隆项目**
```bash
git clone https://github.com/kaier0922/myerp.git
cd myerp
```

**2. 导入数据库**
```bash
mysql -u root -p 你的数据库名 < database.sql
```

**3. 配置数据库连接**

复制配置文件模板并修改：
```bash
cp config.example.php config.php
```

编辑 `config.php`，填入数据库连接信息：
```php
define('DB_HOST', 'localhost');
define('DB_NAME', '你的数据库名');
define('DB_USER', '数据库用户名');
define('DB_PASS', '数据库密码');
```

**4. 配置短信服务（可选）**

复制短信配置模板：
```bash
cp sms_config.example.php sms_config.php
```

编辑 `sms_config.php`，填入腾讯云短信的 SecretId、SecretKey 等信息。

**5. 设置文件权限**
```bash
chmod 755 uploads/
chmod 755 assets/
```

**6. 配置 Nginx**

参考以下配置：
```nginx
server {
    listen 80;
    server_name 你的域名;
    root /www/wwwroot/你的目录;
    index index.php;

    location ~ \.php$ {
        fastcgi_pass unix:/tmp/php-cgi-74.sock;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }

    # 禁止uploads目录执行PHP
    location ~* ^/uploads/.*\.(php|php5|phtml)$ {
        return 403;
    }
}
```

**7. 创建超级管理员**

在数据库执行：
```sql
-- 先生成密码hash（在服务器上执行）
-- php -r "echo password_hash('你的密码', PASSWORD_DEFAULT);"

INSERT INTO users (phone, password, nickname, role, status, created_at)
VALUES ('你的手机号', '上面生成的hash', '系统管理员', 'super_admin', 1, NOW());
```
